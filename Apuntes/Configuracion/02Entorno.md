## Creacion del entorno virtual

- Ejecutar en la terminal:
```bash
pip install virtualenv
```

- Crear el entorno virtual:
```bash
virtualenv entorno
```

- Generar un archivo .gitignore y agregar la carpeta de tu entorno virtual.

- Activar entorno virtual en windows: (entorno es el nombre que le pusiste)
```bash
entorno\Scripts\activate
```

- Activar entorno virtual en windows: (entorno es el nombre que le pusiste)
```bash
source entorno/bin/activate
```
